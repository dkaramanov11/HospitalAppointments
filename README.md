# Hospital Appointments

An ASP.NET MVC 5 application for managing hospitals, doctors, and patients.

## Features

- Create, view, edit, and delete hospitals, doctors, and patients.
- Assign doctors to hospitals.
- Add patients to doctors and view them on the doctor's details page.
- Display hospital images from URLs.
- Validate patient names and five-digit patient codes.

## Technologies

- C#
- ASP.NET MVC 5 (.NET Framework)
- Entity Framework 6
- Razor views

## Getting started

Open `HospitalAppointments.sln` in Visual Studio, restore NuGet packages, and run the application with IIS Express.
